Snapshot Sensors

Expose camera snapshots as HomeKit motion sensors using on-device object detection.

How sensors work
Each Sensor becomes one HomeKit motion sensor that triggers when any of its selected categories is detected above the threshold.
  • Categories — animals, people, vehicles.
  • Name — optional. Leave blank to auto-name it.
  • Threshold — optional confidence cutoff from 0–1 (default 0.5).
